# نجمي ستور

نجمي ستور هو مشروع موقع ويب يهدف إلى تقديم تجربة تسوق فريدة للمستخدمين. يحتوي المشروع على هيكل بسيط وسهل الاستخدام، مع تصميم جذاب وميزات تفاعلية.

## هيكل المشروع

- **src/index.html**: الملف الرئيسي لمستند HTML للموقع. يعمل كنقطة دخول ويحتوي على هيكل صفحات الويب.
- **src/css/style.css**: يحتوي على أنماط الموقع. يحدد المظهر البصري لعناصر HTML، بما في ذلك التخطيط والألوان والخطوط والاستجابة.
- **src/js/main.js**: يحتوي على كود JavaScript للموقع. يتعامل مع التفاعلية، مستمعي الأحداث، وأي تحديثات محتوى ديناميكية على صفحات الويب.
- **src/assets**: دليل مخصص لتخزين الصور والخطوط وملفات الوسائط الأخرى المستخدمة في الموقع.
- **package.json**: ملف تكوين npm. يسرد التبعيات، والبرامج النصية، والبيانات الوصفية للمشروع.

## إعداد المشروع

1. قم بتنزيل أو استنساخ المشروع إلى جهازك.
2. افتح سطر الأوامر وانتقل إلى دليل المشروع.
3. قم بتثبيت التبعيات باستخدام الأمر:
   ```
   npm install
   ```
4. لبدء المشروع، استخدم الأمر:
   ```
   npm start
   ```

## الميزات

- تصميم متجاوب يتكيف مع مختلف أحجام الشاشات.
- تجربة مستخدم سلسة مع تفاعلات ديناميكية.
- إمكانية إضافة وتعديل المحتوى بسهولة.

## الاستخدام

يمكنك تعديل الملفات في دليل `src` لتخصيص الموقع وفقًا لاحتياجاتك. تأكد من تحديث `package.json` عند إضافة أي تبعيات جديدة.
